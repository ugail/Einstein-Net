# Einstein-Net

Neural networks with Einstein's field equations built in.

Einstein-Net is a research programme on neural solvers for general relativity. The idea is
that a network should not be asked to learn what the equations already dictate. The output of a network can be  assembled so that it is within the  constraint manifold by construction. The training objectives are
coordinate-invariant, and every output comes with an estimate, and where possible a proof, of how
far it can be trusted.

## Reproducibility

Every paper folder contains the executed notebooks, the scripts that produced the trained weights
and the reference tables, the results they produced, the figures and the manuscript source. All
runs are deterministic from their seeds, and the commands are listed in that folder's README.
